# Сравнение двух средних в UIKit

Обновлено: 19.10.2026 22:35 Europe/Minsk. Этап: готово, проверено.

Поручение Алексея: два отдельных графика на одних и тех же 100 попытках — текущее взвешенное среднее и среднее квадратичное с весами по давности. Только UIKit; рейтинг игры не менять.

| Блок | Статус | Критерий |
|---|---|---|
| Подготовка | Готово | Предыдущая реализация сохранена в 3e24796; файлы UIKit чистые, соседние изменения сохраняются |
| Два графика | Готово | Одинаковые данные, окно 50, веса 1/.92/.92², шкалы и выбранная попытка; разные формулы и явные подписи. Две отдельные карточки и открытие каждой модалкой |
| Проверки | Готово | Независимый расчёт всех 100 точек и прежний JS-тест PASS; старое среднее не изменилось. Браузер 1100/320 px: геометрия/данные/шкалы одинаковы, выбор связан, оба окна и закрытие работают, консоль чистая |
| Итог | Готово | Снимки и доказательства сохранены, изменения только UIKit/тест/документация; без Android/сервера/RC/публикации |

Формулы: обычное Σ(w·t)/Σw; квадратичное √(Σ(w·t²)/Σw). Одинаковое окно последних 50 подходящих попыток после каждой точки; действующий в примере порог 0, короткие положительные результаты учитываются в обоих вариантах. Исходный набор 100 демонстрационных результатов не меняется.

Предыдущая задача: [график 100/50](2026-10-19-average-chart-modal.md). [Живой UIKit](http://127.0.0.1:8896/?v=average-chart-rms-1#average-chart), [результат и проверки](../../docs/release-evidence/average-chart-rms-20261019/README.md).

Математический результат: текущее 9,263854161690324 с; квадратичное 10,995868454706817 с; разница +1,732014293016493 с (+18,7%). Проверены порог, короткие попытки, равные результаты, давность, независимость от первых 50 для текущей точки и монотонность RMS при улучшении попытки.

Только демонстрация: расчёт рейтинга в игре не изменён. Следующий шаг — оценка Алексеем двух графиков; внедрение новой формулы требует отдельного решения. Навык session-memory использован для сохранения результата и ограничения объёма задачи.
