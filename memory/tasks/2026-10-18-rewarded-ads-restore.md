Yandex официально не поддерживает server-side rewards: https://ads.yandex.com/helpcenter/en/support/faq/sdk-integration . Не имитировать SSV и не менять рекламную сеть. Рабочий выбор: штатный SDK callback + серверная одноразовая сессия и ограничения повторов. Клиентский callback сам по себе не защищает от модифицированного клиента. Внутренняя сборка сохраняет официальные demo IDs (не live-монетизация). Правила возраста/отзыва сохраняются.

Используемые навыки: session-memory, supabase. Git push / Play / live реклама не входят в работу.

Начат отдельный SDK-probe profile с настоящим Yandex demo-rewarded. При первой проверке старые2 fixture теста начисляли деньги также на новом session-start; fixtures исправлены, повтор51PASS. В старом probe после изоляции legacy оставались2 несуществующих UI-функции: feedback переведён на текущий экран, achievements endpoint явно retired.

Настоящий SDK на Huawei PASS; Back рекламный экран не закрывает, штатные кнопки skip → X после earned возвращают в приложение. Это поведение SDK; кликов по рекламным ссылкам не было. SQL canary под production runtime с полной rollback PASS: configured40, owner-session/idempotency/cooldown; настоящих игроков не менял. Первая canary попытка policy_invalid из-за отсутствующего служебного ok у сохранённого snapshot, тестовый wrapper исправлен; бизнес-код не менялся.
