# UI Kit: слои кнопки, сигнал готовности и волна торможения

Обновлено: 23.10.2026 22:31 Europe/Minsk.
Источник: прямое поручение Алексея после просмотра #brake.
Текущий этап: изменения готовы в UI Kit, проверены и визуально осмотрены.

Цель: кнопка на полу, враги/герой выше; достижение полной зарядки отмечается одной вспышкой и более зелёным готовым цветом; нажатие создаёт видимую расходящуюся волну, связывающую кнопку с замедлением врагов. Новые указания Алексея: квадрат со скруглениями в стиле настоящего интерфейса, готовая кнопка приподнята с тенью, нажатая утоплена, через8с поднимается обратно.

| Подзадача | Статус | Критерий завершения | Результат |
|---|---|---|---|
| Квадратная игровая кнопка | Готово | Материал/скругления как в Untouch, размер не больше героя, подъём/тень готовой и утопленное нажатие | Скруглённый SVG-квадрат, поднятие/основание/тень; фон/периметр по часовой стрелке |
| Исправить слои | Готово | Враг и герой перекрывают кнопку при пересечении | Кнопка1 / волна2 / враги3 / герой4; elementFromPoint и наглядные примеры PASS |
| Сигнал готовности | Готово | Одна вспышка при переходе в ready, затем более зелёная кнопка; повторная перерисовка не мигает | Однократная320мсвспышка, зелёный градиент; 25повторныхready не перезапускают |
| Волна нажатия | Готово | Несколько тонких кругов от кнопки по полю, отклик врагов; края обрезаны рамкой | mountBrakeWave: 3кольца/680мс,160мсотклик врага; локальный preview |
| Проверки и показ | Готово | Перекрытие, готовность, повтор/очистка, reduced-motion, 320px, кадры/контракт | Новые8сценариев + прежние11/8сцикл PASS, кадры осмотрены; контракт обновлён |

Рабочие решения агента: прозрачные мятные кольца по плоскости поля, без непрозрачной заливки/тряски всего экрана; короткий отклик врага при достижении волной. Глобальный откат скорости остаётся прежним; движение плавно замедляется. Отдельный реальный звук не добавляется — поручение на визуальный образ звуковой волны. При reduced-motion — статичный короткий отклик вместо расширения. Основная игра/RC/релизы не входят в задачу.

Физический телефон не использовался, это браузерный UI Kit.
