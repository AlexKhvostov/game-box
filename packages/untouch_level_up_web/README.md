# Untouch Level Up · Telegram / Web / Vue

Самостоятельный игровой компонент: локальное видео, программные конфетти, семь исходных щитов, холодные вращающиеся лучи, игровой баннер ранга и объёмная кнопка. Стили и код UI Kit не нужны. Все ресурсы входят в пакет, внешних запросов к сервисам генерации нет.

## Подключение в Telegram Mini App

Добавить локальную зависимость в `telegram-app/package.json`:

```json
"@untouch/level-up": "file:../packages/untouch_level_up_web"
```

```vue
<script setup lang="ts">
import {ref} from 'vue';
import UntouchLevelUp from '@untouch/level-up/UntouchLevelUp.vue';
import type {LevelNumber} from '@untouch/level-up';
const newLevel=ref<LevelNumber>(3);
const showLevelUp=ref(true);
// pauseGame/resumeGame — существующие действия вызывающего игрового экрана.
</script>
<template>
  <UntouchLevelUp v-model:open="showLevelUp" :level="newLevel"
    :muted="true" @open="pauseGame" @close="resumeGame"
    @accept="continueAfterLevelUp" />
</template>
```

Пример собран изолированно в `examples/vue/dist`; исходники рядом. `examples/vue` можно собирать обычным Vite после установки его зависимостей. В текущем репозитории проверен `tools/build_level_up_web_example.mjs`, использующий уже установленный инструментальный комплект Telegram.

Vite автоматически включает MP4/PNG/SVG благодаря статическим URL ресурсов. Для другого размещения файлов есть необязательный `assetBase`: URL каталога, содержащего `celebration.mp4`, `poster.png`, `final-frame.png`, `shields/level-1.svg`…`level-7.svg`.

## Без Vue

```js
import {LevelUpModal} from './index.js';
// Подключить level-up.css рядом с модулем.
const modal=new LevelUpModal({level:3,muted:true});
const result=await modal.result;
if(result.reason==='accept') continueAfterLevelUp(result.level);
```

`standalone.html` показывает именно этот вариант без UI Kit. При загрузке через HTTP окно открывается автоматически.

Параметры: `level`1–7, `muted`, `reduced`, `assetBase`, `onAccept`, `onClose`, `onPhaseChange`. Методы: `setLevel`, `setMuted`, `close`, `destroy`. `result` разрешается один раз со значениями `{reason:'accept'|'dismiss'|'dispose',level}`; `destroy()` не вызывает callbacks принятия/закрытия. `onClose` вызывается после100мс выхода. Полные типы — `index.d.ts`.

Для Vue: `v-model:open`, `level`, `muted`, `reduced`, `assetBase`; события `open`, `accept`, `close`, `phase`. При снятии компонента со страницы плеер/кадры/таймеры освобождаются. `open` позволяет приостановить игровую сцену, `close` — возобновить после завершения закрытия.

`LevelUpAnimation` также принимает `locale: 'ru' | 'en'` и метод `setLocale`. Если видео не начинает двигаться или останавливается на8с, сцена переходит к неподвижному финальному изображению со щитом. Каждое реальное продвижение видео начинает этот срок заново; обычное воспроизведение и его длительность сохраняются. Пауза, уход приложения в фон и уничтожение компонента освобождают этот таймер.

Poster и финальная PNG-плашка сначала полностью загружаются, проверяются по структуре/CRC/IEND и декодируются. Допускается одна повторная загрузка каждого изображения. Повреждённое или неполное изображение не показывается. Если получить готовую плашку не удалось, остаются щит и обычная надпись «Анимация недоступна»; этот аварийный вид не считается полным соответствием Android. Кнопка продолжения принадлежит вызывающему окну и остаётся доступной.

Если уход в фон прервал загрузку плашки, она сохраняет состояние ожидания и возобновляется после возвращения в видимый документ. Общий бюджет остаётся равен двум запросам на изображение, включая прерванные запросы. Готовые и окончательно неудачные изображения повторно не запрашиваются. Возвращение плашек само по себе не запускает видео или callback награждения. Запоздавший pause после уже возобновлённого видео игнорируется по фактическому состоянию paused.

Не начислять награду повторно в callback: компонент получает уже подтверждённый новый уровень. Сам он не меняет профиль, баланс и сервер. Выбрать один способ продолжения: callback либо ожидание `result`.

## Согласованная анимация и части

- Одна принятая MP4-основа для всех уровней,5,175с/768×960/24Гц.
- Щит начинает выходить с2с за0,8с; ширина50%, центр75%высоты.
- 24пучка/3скорости18–12–8,5с/blur1,1px; на конце видео лучи замирают.
- 56фрагментов конфетти; после конца1,6с движения+0,8с затухания, затем остановка Canvas.
- Вход окна160мс/8px, выход100мс. Баннер/кнопка имеют отдельное мягкое появление.
- DOMчасти: `data-part=surface/header/scene/rank/actions/accept`. В продукте нет демонстрационных управляющих кнопок.

Проверено: Vue3.5.44/TS/Vite8.3.4, IABвсе7уровней, один srcвидео, приём/закрытие/Promise,320×568/390×844, безвнутреннегоскролла. Журнал браузера без ошибок. Интеграция в основной игровой маршрут и физический Telegram-клиент ещё не проводились. Шрифты используют системный стек; исходная графика принадлежит проекту Untouch. `manifest.json` фиксирует SHA256 переданного комплекта.

Дополнение14.11.2026: интеграция в игровой маршрут реализована отдельно; targeted browser039 проверил нормальное окончание, отклонённый play, остановку до metadata/после прогресса, неполные PNG, постоянный отказ изображений, reduced motion, фон и уничтожение. Физическая приёмка финального039 выполняется отдельно; прежний абзац описывает исходную проверку пакета12.11, а не текущий статус Telegram.
