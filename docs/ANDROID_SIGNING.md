# Ключ загрузки Untouch

По указанию Алексея от 09.10.2026 рабочий комплект хранится внутри проекта: `.private/android-signing/`.

- `upload-keystore.jks` — закрытый ключ, не передавать другим людям или на хостинг.
- `password.dpapi` — пароль, зашифрованный Windows для текущего пользователя.
- `signing.properties` — путь к ключу и имя upload; открытого пароля нет.
- `upload-certificate.pem` — публичный сертификат.

Папка полностью исключена из Git. Штатные сборки Android/лендинга/Telegram не включают её в результаты. Не архивируйте весь проект для передачи без исключения `.private/`.

`tools/build_phone_apk.ps1` автоматически использует эту папку, если подпись не задана явно. Старый комплект в `D:/Codex/secrets/untouch-google-play` сохранён; он не является новым или иным ключом. Копирование проверено по SHA-256 файлов, пароль расшифрован и ключ открыт keytool; сертификат совпал с Google Play.

Отпечаток публичного upload-сертификата SHA-256: `D1:E6:C2:45:77:DE:48:70:86:09:38:C0:AC:F5:C8:4F:03:9F:2A:74:0D:AA:0C:02:A3:33:42:B2:3B:9E:CD:DE`.

Перенос на другой компьютер: одной копии password.dpapi недостаточно. Нужна отдельная защищённая резервная копия ключа и переносимого пароля (например, в менеджере паролей). Такая копия пока не создана. Пароль не отправлять в чат и не сохранять в документации.
