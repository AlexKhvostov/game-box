# Режим «Этажи» (Floors)

Отдельный режим Untouch рядом с аркадой на рекорд.  
Код: `lib/features/floors/`. Аркада не переписывается — этажи дергают общее ядро поля (`GameWorld`).

См. также: [GAMEPLAY_ADMIN.md](GAMEPLAY_ADMIN.md) · [FIREBASE_SETUP.md](FIREBASE_SETUP.md)

---

## 1. Идея продукта

Игрок исследует **этаж** — сетку **квадратов** (комнат). В каждом квадрате — та же механика уворота от мобов. Цель этажа: дойти до **клетки с выходом на следующий этаж**, выбирая маршрут по сложности.

| Понятие | Смысл |
|---------|--------|
| **Квадрат** | Одна игровая комната (поле с мобами и переходами на стенах) |
| **Переход** | Проём в стене квадрата → соседний квадрат. Сейчас **статичный**; позже может курсировать / открываться с задержкой |
| **Этаж** | Уровень из N×N квадратов (N нечётное: 5, 11, …), старт **строго в центре** |
| **Карта этажа** | Схема сложностей клеток (0–100); цвет от зелёного к красному; старт — серый |
| **Проигрыш** | Снова появление в **стартовом** квадрате (этаж не сбрасывается целиком) |

---

## 2. Две матрицы (модель данных)

### 2.1. Карта этажа — целевой бюджет D

- Размер **нечётный** (центр = старт).
- В клетке `difficulty` ∈ **0…100** — **целевой бюджет**, не жёсткий пакет «всё сразу».
- Флаги: `isStart`, `isFloorExit`.

Фактический микс комнаты = **сумма весов независимых рычагов** (`RoomLoadout`).  
Пример: 1 моб + вращение + стена может быть сложнее, чем 2 моба без вращения и стен.

Код: `floors_loadout.dart` (веса + рецепты), `floors_data.dart` (карта).

### 2.2. Рычаги сложности (расширяемо)

| Рычаг | Примеры | Вес (ориентир) |
|-------|---------|----------------|
| Число мобов | 2 = база; 3–4 дороже | 0 / 22 / 42 |
| Скорость | ×0.65…×1.75 | 0…42 |
| Столкновения | сквозь / бьются | 0 / 18 |
| Вращение | 0 / ~28°/с / ~40°/с | 0 / 22 / 32 |
| Внутренние стенки | 0 / 1 / 2 | 0 / 20 / 35 |
| Скорость дыр | 0 = статично; езда вдоль стены | 0 / 14 / 24 / 36 |
| Соседняя рамка | всегда видна снаружи; проход = своя + чужая дыра | — |
| Дропы (позже) | bonus / debuff | +12 / +14 |

**Самый лёгкий эталон:** 2 моба разных форм, проходят сквозь друг друга, одна рамка, дыры стоят.  
Минимум мобов в бою — **2**. Рамочка у моба = они сталкиваются; без рамки — сквозь.  
На сложных — две рамки; выход только когда обе дыры совпали.  
Этаж 1 = 5×5 → этаж 2 = 11×11 → этаж 3 пока заглушка.

### 2.3. Настройки этажа целиком

| Поле | Этаж 1 | Смысл |
|------|--------|--------|
| `size` | 5 | Нечётный размер карты |
| `maxEnemies` | 4 | Потолок мобов |
| `allowWalls` | true | Разрешить рычаг стенок |
| `allowMovingExits` | true | Разрешить едущие дыры |
| `allowBonusDrops` | false | Плюсы |
| `allowDebuffDrops` | false | Минусы |
| `mapReveal` | fog | Цвет/D — после посещения |

## 3. Цвета карты

| Клетка | Цвет |
|--------|------|
| Старт | Серый |
| Сложность низкая → высокая | Зелёный → жёлтый → красный (по D 0…100) |
| Выход с этажа | Обводка / иконка поверх цвета сложности |

---

## 4. Переходы (сейчас / потом)

**Сейчас:** дыра в рамке (зелёные маркеры опциональны). Скорость дыры — рычаг сложности. На хард-миксах — **две рамки**, проход только при совпадении дыр. Переход — слайд; **~1.5 с защиты**. Clamp смертельных стен.

**Фон / память комнаты:** тинт по D; разгон мобов сохраняется при уходе/возврате.

**Клетка выхода (↑):** зона «Выход» в центре → «Выход найден!».

**Потом:** две рамки / совпадение двух дыр; задержка открытия.

---

## 5. Дропы (позже)

Предмет пролетает по полю, не сталкиваясь со стенами/мобами. Перехват героем → эффект.

- **Бонусы:** кристалл, жизнь, шлем N сек, прыжок N сек, замедление врагов…
- **Дебафы:** ухудшения (замедление героя, ускорение мобов и т.д.) — на высоких этажах / сложностях.

На этаже 1 дропов нет.

---

## 6. Проигрыш и прогресс

- Столкновение со стеной вне перехода или с мобом → комната проиграна → телепорт на **старт этажа**.
- Миникарта: непройденные клетки **серые** (без числа сложности); после визита — цвет и D.
- Достиг клетки `isFloorExit` и «активировал» выход → следующий этаж (пока заглушка «этаж пройден»).

---

## 7. Порядок внедрения

1. Модель данных + этаж 1 (5×5) + таблица полос — **сейчас**  
2. Навигация по соседним квадратам, статичные переходы, миникарта  
3. Курсирующий выход / задержка  
4. Стенки внутри квадрата  
5. Дропы (бонусы → дебафы)  
6. Большие этажи (11×11), туман войны на карте
