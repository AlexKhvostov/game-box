По действующей механике после седьмого дня награда остаётся на уровне дня7; пропуск дня сбрасывает последовательность. Изменение конфигурации не пересчитывает уже выданные бонусы и не сбрасывает кошельки.

Источник работающей экономики — серверный published config, получаемый через api/config.php. В APK сохраняется его снимок для запуска без сети; конструкционные/JSON defaults приведены к тем же целевым значениям. Для получения сетевых изменений полностью перезапустите игру с интернетом.
