# B01 / B02 — улитка и шкала скорости

23.10.2026. Компоненты существующего живого UI Kit. Просмотр: **http://127.0.0.1:8896/#brake**.

Выбранный Алексеем образ — белая улитка с тёмным контуром. По следующему прямому указанию форма теперь квадратная со скруглениями и игровым бликом: готовая кнопка приподнята с тенью, нажатая утоплена. Здесь SVG/CSS-компонент, а не растровая копия экрана. Шкала светло-красная, удаляемый хвост зелёный.

## B01 — кнопка

`brakeButton(options)` возвращает разметку. `mountBrakeButton(host, options)` монтирует её и возвращает `element`, `setState(update)`, `getState()`, `destroy()`.

| Параметр | Смысл |
|---|---|
| `state` | `uncharged`, `charging`, `ready`, `pressed` |
| `progress` | Доля заряда 0…1, только для charging; uncharged всегда 0, ready/pressed всегда 1 |
| `size` | Размер в пикселях, по умолчанию 44; в демо не больше героя |
| `onPress` | Вызывается при доступном нажатии; не вызывается при disabled |

Кнопка управляется внешним состоянием. Обработчик `onPress` должен перевести её в pressed/charging; сама она не заводит второй независимый таймер. Enter/Space и фокус работают как у обычной HTML-кнопки. Неготовое состояние действительно disabled, не только окрашено иначе.

Фон почти серый (#c1c8c8…#8e9b9d), улитка в неактивном состоянии дополнительно приглушена. Салатовый сектор начинается на 12 часах, идёт по часовой стрелке и заполняет всю площадь скруглённого квадрата через clipPath. Обводка получает тот же progress, начинается с середины верхней стороны и идёт по периметру по часовой стрелке. При половине заряда окрашена правая половина. При полном — весь фон, после перехода в ready он становится более зелёным (#d6ffb0/#a5f579/#66d985).

Готовая лицевая площадка приподнята на 4 внутренних единицы SVG (около1,8px при размере44px), видны основание и тень. При переходе в ready однократно вспыхивает на320мс; повторные setState(ready) не перезапускают вспышку. Непрерывной пульсации нет. При нажатии площадка утапливается и сжимается на4%; через8с зарядки снова поднимается. Улитка остаётся без надписей и чисел.

## B01.W — волна и уровни поля

Уровни живой сцены: фон0 → кнопка1 → волна2 → враги3 → герой4. Подъём готовой кнопки меняет только её площадку/тень внутри первого уровня, она по-прежнему перекрывается врагами и героем. В галерее добавлены два наглядных примера перекрытия.

`mountBrakeWave(host, {duration=680, reducedMotion, onHit})` возвращает `play(targets)`, `stop()`, `getState()`, `destroy()`. Цель — `{x,y,...}` в координатах поля380×380; onHit вызывается по одному разу для каждой цели, когда первый фронт достигает её исходного положения. Повторный play отменяет прежний эффект и начинает новый. duration должен быть больше160мс.

Три прозрачных мятных кольца расходятся от центра с интервалом80мс и затухают. Волна обрезана рамкой поля, непрозрачной заливки/встряски нет. Враг получает светлый контур примерно на160мс. Это визуальный образ звуковой волны без добавления аудио. Замедление скорости начинается сразу и плавно, декоративное достижение волной не вводит второй игровой таймер.

При паузе/сбросе/скрытии/уходе со вкладки кольца и отложенные отклики очищаются. Reduced-motion заменяет расширение небольшими статичными кольцами и коротким откликом. «Показать волну» в инструментах галереи подготавливает доступную кнопку и запускает полный пример нажатия/отката.

## B02 — скорость

`speedBar({value, max})` возвращает разметку. `mountSpeedBar(host, {value, max, reducedMotion})` возвращает `element`, `setValue(next, {duration})`, `brakeTo(next, {holdMs, fadeMs})`, `getState()`, `destroy()`.

- `max` по умолчанию 150. Значение ограничивается диапазоном 0…max. Сама скорость/единицы/деления/границы визуально не печатаются.
- На полосе только мелкая подпись «скорость врагов». Числовая доступность остаётся в ARIA для программ чтения экрана.
- Светло-красное заполнение (#ffc1c0…#ff8c95) показывает скорость.
- `brakeTo` сразу отделяет сбрасываемый правый участок зелёным (#c5ffb3…#68e59d), сохраняет его 110 мс, затем убирает справа налево за 220 мс. Оставшаяся часть остаётся светло-красной.
- Новое значение или торможение отменяет незавершённую анимацию. Старый кадр не возвращает прежний хвост.
- При prefers-reduced-motion зелёная часть кратко показывается и убирается без плавного движения. Все числовые параметры длительности пока рабочий выбор агента.

## Демонстрация

`brakeKitPage()` и `mountBrakeKitPage(root)` — галерея. Функция mount возвращает очистку: отменяет кадры/таймер эффекта и снимает обработчики. При уходе во вкладку UI Kit предыдущая демонстрация уничтожается; при скрытии окна — ставится на паузу. При возврате страница начинается заново.

В демо согласованная модель `70*((x+3)^0.2−1)`: первая готовность на 8 с активного отсчёта, откат 8 с, отброс расчётного времени 8 с с нижней границей 0. Реальные секунды партии не откатываются. Равные откат/отброс позволяют своевременным нажатием вернуться к исходной скорости; задержки накапливаются. Это демонстрационная модель, а не новая настройка основной игры.

Герой отодвинут вправо вниз для обзора. Демонстрационное нажатие выполняется мышью/касанием/клавиатурой на улитке, а не столкновением героя. Враги в демо получают короткую светлую обводку и плавный переход к меньшей скорости. Прыжки, поражения и столкновения настоящей игры здесь не моделируются. Шапка и герой используют существующие компоненты/ассеты UI Kit.
