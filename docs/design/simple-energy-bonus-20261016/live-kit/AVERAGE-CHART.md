# График среднего результата

Обновлено: 20.10.2026, Europe/Minsk. Алексей утвердил **среднее квадратичное с весами по давности**. Сервер Android API v21 уже использует его; приложение 188 / 1.0.187 собрано, но в Google Play ещё не загружено.

Живой UIKit: `?v=average-chart-rms-live-1#average-chart`. Два отдельных графика сохраняют сравнение на прежних 100 условных попытках: прежнее среднее **9,264 с** и утверждённое квадратичное **10,996 с**. Данные, окно 50, веса и шкалы одинаковы. Выбор попытки связан. Кнопка в рейтинге теперь открывает квадратичный график по умолчанию.

Серверная формула: `sqrt(sum(time² * weight) / sum(weight))`, веса `1, .92, .92² …` от нового к старому, окно последних N подходящих результатов. Фильтрация выполняется перед окном; при действующем пороге 0 короткие положительные попытки учитываются. У каждой исторической точки своё окно N. RC/история/энергия/реклама/покупки не менялись.

Ответ сервера содержит `rules.algorithm = weighted_rms_v1`; ключ производного серверного кэша тоже включает эту версию. Это автоматически пересчитывает прежние агрегаты. Flutter строит RMS-линию для RMS-ответа; старые ответы без метки распознаются как арифметические. Новый локальный owner-кэш v2 сохраняет метку. Неоднозначный v1-кэш прежнего клиента не используется: после обновления приложения для первого среднего нужен успешный ответ сервера, игровые данные сохранены.

Android использует до 200 локальных подтверждённых попыток своего аккаунта и показывает последние 100. Перед обрезкой вычисляется линия с учётом доступной предыдущей истории. Неполная или расходящаяся с сервером история отмечается явно; официальное среднее показывается отдельно. Полная серверная история повторно не скачивается.

SVG в UIKit / CustomPainter в Flutter, без новой библиотеки, постоянных анимаций и расчёта в игровом цикле. На узком экране история прокручивается горизонтально, ось времени закреплена, содержимое модалки прокручивается вертикально. Максимальный масштаб текста 1.4 сохраняется.

Проверки нового расчёта: 118 backend PASS, 60 Flutter PASS, анализ чистый, JS/браузер PASS. Независимая проверка действующей БД подтвердила всех 12 участников рейтинга; производный кэш 29 профилей пересчитан, документы не изменены. Телефон 20.10 не подключён, новая физическая проверка пока не выполнена. [Доказательства](../../../release-evidence/weighted-rms-20261020/README.md).
