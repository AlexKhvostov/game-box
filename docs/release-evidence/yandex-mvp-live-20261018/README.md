# Яндекс для MVP — 18 октября 2026

Обновлено: 18.10.2026 17:11 Europe/Minsk. Код и физическая приёмка готовы. Основная версия 178 установлена на Huawei без очистки. Коммерческая монетизация ожидает активации приложения Яндексом.

Решение Алексея: подключить Яндекс без независимого серверного подтверждения просмотра и без Play Integrity. Для MVP принят риск подделанного события изменённым приложением. Сохранены серверная сумма, одноразовая сессия, однократность начисления, 120 секунд между наградами и 20 успешных наград на аккаунт за календарные сутки UTC+3.

## Что изменено

- Явная сборка `-LiveAds` использует существующие блоки: rewarded `R-M-20184253-1`, interstitial `R-M-20184253-2`. Устаревший запрет live удалён. Demo/off сохранены; два режима одновременно запрещены.
- Нажатие на видео запускает только добровольную rewarded-рекламу для заявленного взрослого; автоматическая межстраничная реклама этим не разрешается. Возраст, отзыв разрешения, отсутствие персонализации/геолокации и явная инициализация сохранены.
- Сборщик записывает режим/ID в `build.json` и допускает `ProductionRelease + LiveAds`; отладочные инструменты и demo для production по-прежнему запрещены.
- В объяснении рекламы пометка о demo показывается только в demo-сборке.
- Кабинет РСЯ: старые `Crystals / 9` заменены на `Energy / 40` в существующем блоке -1. Сохранение проверено повторным открытием. Фактическую сумму награды определяет наш сервер/RC.

## Кабинет и доступность монетизации

Фактически проверено 18.10.2026: приложение Untouch `20184253` в **Тестовом режиме**, оба блока активны. Для активации кабинет требует ссылку на опубликованное приложение. По [официальным правилам Яндекса](https://ads.yandex.com/helpcenter/ru/monetization/app/status), рабочие ID до модерации обслуживают тестовые объявления без дохода; после статуса «Активно» начнут обслуживать настоящую рекламу без замены ID в APK. Тестовый показ не считается доказательством коммерческого дохода.

Кабинет предупреждал о временной нестабильности интерфейса/статистики. Договоры, документы, реквизиты, доступы, магазин и сторонние сети текущей задачей не менялись.
