# Внедрение квадратичного среднего

20.10.2026, Europe/Minsk. Прямое решение Алексея: квадратичная формула утверждена для игры.

## Результат

- Android API **v21 ACTIVE**. `sqrt(sum(w*time²)/sum(w))`, последние 50 подходящих, веса 1/.92/.92², порог 0, допуск с первой попытки. Прежние четыре RC-параметра сохранены, игровой revision не менялся: ручной перезапуск из-за этой смены не требуется.
- Алгоритм обозначен `weighted_rms_v1` в ответе и ключе серверного кэша. Прежние агрегаты автоматически пересчитаны; исходные попытки не изменялись. Прежний fallback тоже использует RMS.
- Приложение/график используют метку ответа. Парсер поддерживает старый ответ без метки; версия клиентского кэша v2 исключает неоднозначный v1, который старое приложение сохраняло без метки. При первом обновлении нужен успешный запрос для заполнения нового кэша среднего. Энергия/попытки/Google-профиль и остальные локальные данные сохраняются.
- График показывает 100 последних сохранённых попыток, выделяет текущее окно 50 и строит RMS после каждой попытки. Неполная локальная история по-прежнему помечена. В подсказке RU/EN объяснено усиление сильных результатов; без вычислений в игровом цикле.
- UIKit сохраняет прежнюю формулу для сравнения; кнопка в рейтинге по умолчанию открывает утверждённую RMS-карточку. [UIKit](http://127.0.0.1:8896/?v=average-chart-rms-live-1#average-chart), [снимок](uikit-rms-modal.png).

## Совместимость и откат

Установленная версия187 принимает дополнительное поле algorithm без изменения контракта чисел: готовое среднее и места получает от сервера. Новое значение появляется при следующем успешном обновлении рейтинга; старое сохранённое значение до этого может оставаться на экране. Новый график/пояснение доставляются с188.

[Серверная публикация](deployment.json): в пакете v20 заменены ровно average-config.mjs, average-ranking.mjs, average-ranking-cache.mjs; 20 зависимостей сохранены, проверено повторным чтением опубликованного пакета. Настройки авторизации оставлены прежними. Резервная v20: `.private/weighted-rms-20261020/android-api-before.json`. Повторная публикация этого пакета вернёт арифметическое среднее; его ключ автоматически пересчитает производный кэш. Миграция/удаление истории для отката не нужны.

Реклама, покупки, экономика, физика, Telegram и доступы не менялись. Push/Google Play-публикации/сообщений/оплат нет. Навыки: Supabase/Postgres — расчёт и кэш; session-memory — решение, план и проверяемый итог.
