## Покупки для участников закрытого тестирования

В Console → «Тестирование лицензий» выбран ровно список `Untouch Closed Alpha` из22 адресов. Это тот же список, который разрешён в Alpha. Поэтому участникам доступны тестовые карты Google. Их не «вшивают в APK»: режим зависит от Google-аккаунта покупателя.

Использовать аккаунт из этого списка в Google Play и тестовый способ оплаты; перед подтверждением Google должен явно показать тестовый заказ без списания. Вход Google внутри игры сам по себе этого не гарантирует. Обычные реальные способы оплаты не использовать для проверки. Аккаунт вне списка не получает бесплатные покупки только из-за закрытого канала. В этом этапе новые покупки не выполнялись, список лицензий не изменялся.

[Действующие настройки](license-testers.txt), [официальные правила Google](https://developer.android.com/google/play/billing/test).

## Реклама в208

Живая РСЯ: приложение20184253 — **«Тестовый режим»**, блоки rewarded `R-M-20184253-1` и interstitial `R-M-20184253-2` — **«Активно»**. В208 стоят эти publisher-ID; demo-режим сборки выключен. При тестовом статусе самого приложения Яндекс отдаёт тестовую рекламу, без дохода. Для коммерческих показов позднее нужны опубликованная ссылка, подтверждение доступа и модерация РСЯ. Сам закрытый канал Google рекламный SDK не выключает.

Условия показа:18+, отдельное сохранённое согласие рекламных данных, сеть/доступное объявление. Отказ, неизвестный возраст и<18 блокируют рекламу. Согласие AppMetrica отдельно. Премиум/энергоподписка отключают обычную межстраничную рекламу. Обычная реклама — после результата/возможного «Поделиться» в паузе перед следующей игрой; наградная — только по кнопке.

Живой RC63/schema2 повторно прочитан без изменения:180сек после запуска и первые10 завершённых партий свободны; также начальная отсрочка210сек, интервал220сек, минимум6 энергии для обычной рекламы. Rewarded:40 энергии,120сек между наградами, максимум20/сутки. Работоспособность настоящего SDK/переходов/однократной награды проверена на финальной отдельной QA208 из тех же исходников; это не новый коммерческий показ в основном приложении. Прежний физический тест publisher-блока в тестовом статусе также сохранён в отчёте18октября.

[Текущий статус РСЯ](yandex-app-status.txt), [RC](live-ads-config.json), [официальные статусы Яндекса](https://ads.yandex.com/helpcenter/ru/monetization/app/status), [предыдущая проверка publisher-блока на Huawei](../yandex-mvp-live-20261018/main-ad-result.json).
