# Доводка стрелок и иллюстраций инструкции

19.10.2026 18:43 Europe/Minsk. Готово в UIKit и Flutter-компоненте.

По замечанию Алексея убраны обычные шрифтовые/контурные стрелки. Новые стрелки — цельные рисованные формы со скруглением, трёхцветным градиентом, небольшим объёмом и мягкой подсветкой. В обоих вариантах используется одинаковый силуэт. Смягчены края уголка телефона, кольца часов и контур руки; один вытянутый палец явно указывает на кнопку. Нет новых постоянных анимаций, текст/награда/запуск SDK прежние.

- [UIKit](http://127.0.0.1:8896/?v=soft-arrows-3#rewarded-guide), [фактическая отрисовка Huawei QA196](phone-normal.png), [320×640](phone-320x640.png).
- [64 Flutter PASS](flutter-tests.txt), [анализ чистый](dart-analyze.txt), [8 браузерных сценариев PASS](uikit-verification.json).
- [Физическая проверка](phone-verification.json): готовый игровой виджет, обычный/малый экран, ошибок нет. Все API перехвачены; этот прогон проверяет графику, а не новую настоящую рекламу. Полный SDK-цикл проверен ранее в186 и здесь не менялся.

После проверки QA удалён только из Android user0, основная игра сохранена и остановлена, исходный размер экрана восстановлен; USB2 сохранён, forward8897 снят. Облако, баланс владельца, биллинг и рекламные функции не менялись.

Новый production AAB в этой доводке не собирался. Предыдущий186 остаётся с прежними стрелками; для следующей публикации нужна новая версия из актуального кода. Исторические доказательства186 сохранены отдельно и не заменены текущими снимками.

Навык session-memory: сохранены результат, проверки и следующий шаг.
