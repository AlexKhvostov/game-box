# Android: скорость и педаль торможения

Обновлено 24.10.2026 00:19 Europe/Minsk. Ветка `codex/android-brake-speed`; слияния в main и Git push нет.

## Результат

Механика перенесена в Android: формула `0 + 70 × ((x + 3)^0.20 − 1)`, первая готовность/перезарядка/откат расчётного времени6/6/6с. Сглаживание физического торможения0,18с, реальный секундомер не откатывается. Педаль нажимается пересечением или под стоящим героем при готовности; в прыжке не нажимается. Проверка столкновения предшествует педали: погибший герой не спасается нажатием задним числом. Старая очередь результатов версии1 сохраняется, новые партии используют версию2.

Педаль квадратная, размером не больше героя, под врагами и героем. Прозрачность растёт вместе с зарядом, фон заряжается по часовой стрелке. Серая улитка становится светлой, готовая педаль приподнята, вспыхивает и зеленеет. Нажатие утапливает её и выпускает прозрачную волну; враги кратко подсвечиваются. Шкала над полем: светло-красный рост и зелёный исчезающий участок, без видимых чисел. При отключении шкалы место не сохраняется. Размер поля и жесты управления прежние.

Android читает те же10общихпараметров, что Telegram, включая независимые `enemyPace.brakeEnabled` и `enemyPace.speedBarEnabled`. Оба по умолчанию true. Выключенная педаль отсутствует и не тормозит; функция скорости продолжает расти. Настройки фиксируются на партию. Код общей админки готов с прошлого этапа, её отдельная публикация и запись живых значений RC пока не выполнялись: опубликованный старый RC использует согласованные defaults новой модели.
