# Android Flexible Update · проверка реализации

24.10.2026, Europe/Minsk. Пользователь поручил реализацию обычного сценария, а не публикацию. Ветка `codex/android-flexible-update`.

## Результат

Реальная интеграция официальной библиотеки Google Play собрана в Android APK197/1.0.196. Реализованы фоновая загрузка, предложение в свободном меню после закрытия результата, отложенная установка, сохранение состояния, ошибки и подтверждённый успех. Не прерываются партия/начало/результат/другое окно/стартовый Google/возраст. Сначала сохраняются локальные данные, затем установка по явному действию пользователя.

Кадры сохранены из отдельной release QA со старыми тестовыми жизнями/кристаллами; они не показывают профиль владельца. Четыре основных кадра осмотрены визуально. Состояния Google Play для загрузки/готовности/ошибки синтетические. Метод-канал настоящего Android-моста вызван отдельно: USB-установка ожидаемо вернула supported=false, а не пыталась обновить основной пакет.

Проверены реальные нажатия «Позже»/«Скачать»/«Перезапустить и обновить», настоящая партия и завершение, отсутствие окон/плашек во время партии/результата, восстановление отложенной кнопки после фон/foreground и ошибка после разрешённого перезапуска. Основная установленная196 осталась196, удаления/очистки не было, обе игры остановлены, ADBforward удалён, USBstay-on2сохранён.

Физическая QAкопия создана до последней защитной проверки некорректного номера готовой версии и форматирования GameHomeScreen; сценарий использует корректные197→198 и повторно покрыт финальными Dart-тестами. Последняя защита дополнительно собрана в финальном основном APK197.

## Ограничение реальной доставки

Настоящие согласие/скачивание/установка из Google Play не выполнялись. Нужны две доступные совместимые Play-версии, нижняя уже с интеграцией. GooglePlayпубликация, mainmerge и push не выполнялись. APK197локальный; подпись установки из Playне заменяет.
