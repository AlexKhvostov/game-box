# Два графика среднего в UIKit

19.10.2026, Europe/Minsk. Поручение: сравнить две формулы на прежних 100 попытках, не менять игровой рейтинг.

- [UIKit](http://127.0.0.1:8896/?v=average-chart-rms-1#average-chart): две карточки одна под другой. Одна шкала 0–20 с, одинаковые столбики, последние 50 выделены. Выбор попытки связан. Каждую карточку можно открыть отдельным окном.
- Действующая формула: Σ(w·t)/Σw = **9,263854161690324 с**.
- Квадратичная: √(Σ(w·t²)/Σw) = **10,995868454706817 с**.
- В обоих случаях веса по давности 1/.92/.92²; историческая линия после каждой точки использует своё окно 50. Короткие положительные попытки учитываются. Разница текущих значений **+1,732014293016493 с (+18,7%)**.

Проверки:

- [Математика](math-check.json): независимый расчёт каждой из 100 точек, прежний результат без изменений, одинаковый вход, давность, окно 50, порог, короткие/равные результаты и улучшение одной попытки. PASS.
- `node tools/test_average_chart_uikit.mjs`: прежние проверки PASS. `node --check …/app.js`: синтаксис корректен.
- [Браузер](browser-check.json): 1100×900 и 320×640, по 100 столбиков/50 активных, геометрия всех столбиков и шкалы одинаковы, линии различаются, горизонтального переполнения страницы нет. На узком экране прокручивается история, ось закреплена.
- Реальное нажатие попытки 80 обновило оба графика: 10,154 с; старое среднее 9,798 с, RMS 11,307 с. Открытие обоих окон и закрытие проверены. На 320×640 крестик виден, содержимое модалки прокручивается. Ошибок/предупреждений консоли нет; размер браузера восстановлен.
