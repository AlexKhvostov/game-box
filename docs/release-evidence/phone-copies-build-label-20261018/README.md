## Изменения

По прямому поручению Алексея удалены два старых QA-пакета: `com.best4u.untouch.uiprobe.simpleenergy`176 и `.uiprobe.review`175. Основной пакет `com.best4u.untouch`178 оставлен с данными. После проверки новой временной QA179 она также удалена. В финале должна остаться только актуальная основная игра.

Gradle автоматически берёт номер из `flutter.versionCode`: основная **Untouch 179**, изолированные проверки **QA179 Untouch**. Сборщик записывает `applicationLabel` в `build.json`; номер не задаётся вручную отдельно от версии. Правило сохранено в [инструкции физических проверок](../../ANDROID_PHYSICAL_TESTING.md).

Дополнительное замечание пользователя: враги после касания перескакивали из видимых до старта позиций. Найдены две причины в `_launchLocalRound`: мир пересоздавался с seed при касании, затем враги возвращались к home-позициям. Теперь seed/ключ будущей попытки готовятся вместе с ожидающим полем; при касании журнал однократно принимает этот ключ, сохраняется тот же мир и его текущие позиции/углы/направления. Меняется только скорость для игры. Старый метод `snapEnemiesToHome` удалён.

Для проверки результата replay получает небольшой начальный pose (положение, направление и угол каждого врага). Размеры, скорость, ускорение и вращение по-прежнему определяются конфигурацией/seed; неверная скорость, нечисловые значения и выход за поле отклоняются. Старые proof без pose принимаются. Серверный секундомер не включает ожидание до касания.
