# Android185: результаты и ограничения

19.10.2026 14:43 Europe/Minsk. Версия **1.0.184 (185)**, название **untouch**. Код проверен, подписанный AAB готов. **185 в Google не загружена**; основная игра на Huawei остаётся184.

## Первый запуск

Точный snapshot из опубликованного184 отличается от серверного RC51 только блоком среднего рейтинга. Стартовая загрузка Firebase ждала750мс; поздний ответ сохранялся на следующий запуск. Сервер сравнивал общий hash, требуя перезапуска без изменения физики игры.

Текущие настройки теперь приходят с профилем и применяются между попытками, сохраняя аккаунт, очередь результатов и кошелёк. Во время попытки правила не меняются. Сервер допускает только известные опубликованные старые ревизии с одинаковыми физикой и экономикой. Неизвестные идентификаторы и несовместимые правила отклоняются; отклонённые результаты повторно не начисляются.

Чистый Huawei QA со старым snapshot и облачный сценарий прошли без ручного перезапуска. [До](cloud-before.json), [после](cloud-after.json), [Huawei](phone191/startup-and-game.json).

## Резкие движения

Неизменные фон/сетка/нижняя поверхность отделены от движущихся объектов. Неактивные способности больше не перестраивают оформление каждый кадр; текст активного отсчёта меняется при изменении десятых секунды. PointerMove немедленно запрашивает перерисовку, без сглаживания. Короткие звуки готовятся до управления.

На физическом Huawei P30 Lite в profile проверены резкие перемещения и развороты, затем настоящие Android-свайпы по65мс. В повторном одинаковом сценарии со звуком время построения интерфейса p95 **9.135→4.532мс**, p99 **9.903→7.215мс**. Это одна сопоставимая пара прогонов, не универсальная гарантия ускорения вдвое. [До](baseline-sound/), [после](final/); промежуточные измерения сохранены.

**Полное отсутствие фризов не подтверждено.** Редкие интервалы кадров до≈100мс остались. GPU-время не улучшилось одинаково во всех сценариях. Для причины этих выбросов нужна отдельная трассировка; стабильные60FPS не заявляются.

Резкое движение до первого кадра выявило дополнительный дефект: немедленное столкновение давало0мс, сервер отклонял результат. Теперь перед таким движением записывается минимальный физический шаг1мс в ту же проверяемую последовательность. Завершённый результат не подменяется. Настоящие попытки **1,998,2129,1148мс** приняты сервером; последние три без искусственной неуязвимости. [Раунды](phone192/normal-games.json), [серверная сверка](native-cloud-verification.json).

В длительном замере кадров отдельная fixture содержала стартовую защиту3600с. Этот замер не выдаётся за обычный раунд и не заменяет реальные столкновения/запись результатов выше.

## Средний рейтинг

В существующем Remote Config опубликованы только **minAttempts=1, minDurationMs=0**. Окно50 и вес предыдущего результата92% сохранены; параметры редактируются в админке. Положительные серверные результаты учитываются с первой попытки, включая короткие; сохранённая история пересчитывается без дополнительной игры.

Первый настоящий1мс вошёл в рейтинг. [Публикация RC52](rc-publication.json), [подтверждение](native-cloud-verification.json). Другие параметры экономики и рекламных лимитов не менялись.

## Инструкция и реклама

Главное окно энергии открывает отдельную инструкцию. В ней два нумерованных шага с настоящими SDK-фрагментами и стрелками: дождаться кнопки перехода справа вверху, затем закрыть следующий экран крестиком ×. Сохранены пояснения о награде, условиях и возможных отличиях рекламных материалов. Кнопка запуска SDK находится в инструкции.

[Итоговый экран Huawei QA192](phone192/ad-two-steps.png). В промежуточной191 упаковка пропустилаPNG; физическая проверка выявила это, явное включение ресурсов исправило. Изображения191 не выдавать за итог.

Реальный SDK на Huawei показал деморолик; после возврата сервер начислил **48→88 (+40) ровно один раз**, баланс сохранился после перезапуска. Следующие три обычных раунда:88→85. Ручное нажатие обоих рекламных элементов именно в этом прогоне не зафиксировано: при следующем осмотре игра уже вернулась из SDK. Подтверждены показ/возврат/награда, но новый полный протокол закрытия каждого креатива не заявляется. Фрагменты инструкции взяты из настоящих SDK-снимков18.10.

Production AAB содержит существующие рабочие publisher-блоки Яндекса;120с/20наград в сутки сохранены. Реклама и функции не отключены. Коммерческий доход, настоящие оплаты и все рекламные материалы этим тестом не проверены.
