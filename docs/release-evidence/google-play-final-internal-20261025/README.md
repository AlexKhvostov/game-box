## Декларация: существенные уточнения

Добавлены Analytics collect/share для идентификаторов пользователя/устройства, истории покупок, действий интерфейса и игровых действий; Diagnostics и Other app performance — добровольные Analytics collect/share. Прежние функциональные потоки имени, email и обратной связи сохранены. Автоматические отчёты об ошибках/ANR, системная геолокация Android и AD_ID выключены.

Приблизительное местоположение указано отдельно: Google требует учитывать регион, выведенный из IP; AppMetrica подтверждает такую обработку. Это добровольные collect/share с целями Analytics и Advertising. Рекламная цель — рабочий вывод из обработки IP для регионального подбора Яндексом и согласованного рекламного режима. IP раскрыт в окне аналитики, возможный регион — в опубликованной политике. Промежуточный preview из 10 типов сохранён только как история; итоговая форма содержит 11 типов.

Источники: [Google Play](https://support.google.com/googleplay/android-developer/answer/10787469?hl=en#types), [AppMetrica IP](https://appmetrica.yandex.ru/docs/en/data-security/ip-masking), [AppMetrica Data Safety](https://appmetrica.yandex.ru/docs/en/data-security/google-data-safety), [Yandex Ads SDK 8](https://ads.yandex.com/helpcenter/en/dev/android/app-privacy-android), [региональный подбор Яндекса](https://yandex.com/support/direct/en/troubleshooting/shows).
