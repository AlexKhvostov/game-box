## Сборка и ключ

Исходники переведены на подтверждённый пакет. Android minSdk 24, targetSdk 36. Google Play Billing 8.0.0, Yandex Mobile Ads 8.5.0. Старый google-services.json относится к com.boxgame.game_box, OAuth-клиентов в файле нет; к новой сборке он не применяется. Нынешние профиль, экономика, конфигурация и общий рейтинг используют HTTPS PHP/MySQL. Firebase Analytics отключён в манифесте; устаревшие зависимости ещё находятся в проекте, они не считаются активной аналитикой.

По прямому разрешению Алексея создан upload key RSA4096. Рабочий закрытый ключ и настройки: `.private/android-signing/` проекта, исключены из Git; исходная внешняя копия сохранена. Пароль записан только в защищённом Windows DPAPI виде, ограничен текущей учётной записью Windows. Репозиторий содержит только инструменты. Публичный SHA-1 upload-сертификата: `9D:10:1B:F5:D1:B7:66:B7:0F:0A:9E:CF:7C:1F:BF:34:F9:D5:09:FB`.

Это ключ загрузки; Google Play App Signing создаёт/использует отдельный сертификат устанавливаемой версии. Для Google OAuth Android нужно регистрировать SHA-1 App Signing из Play Console, а для локального подписанного APK — SHA-1 upload key.

После загрузки AAB в Play подтверждены: App Signing активен, SHA-1/SHA-256 ключа загрузки совпадают с локальными. SHA-256 устанавливаемого сертификата из Play: `A1:28:21:30:E3:01:EB:AB:B4:4F:88:04:F4:A6:F6:9A:E9:8D:3D:E9:E4:64:F5:6A:03:4C:9D:A0:F1:F0:D7:01`. SHA-1 App Signing пока не получен: копирование вернуло пустой буфер, скачивание публичного сертификата завершилось timeout. Актуальный путь консоли: «Защищено Google Play» → сведения «Защита Google Play» → «Управление функцией подписания приложений».

Для сборки используйте `tools/build_phone_apk.ps1 -AppBundle`. Скрипт увеличивает версию, создаёт новую папку releases, не перезаписывает архивы. Прямая Gradle-сборка release AAB без закрытого ключа подписи теперь также запрещена. Для APK убрать -AppBundle; чтобы сохранить уже подготовленную версию AAB для сопутствующей APK — добавить -NoBump. По умолчанию реклама явно выключена; -DemoAds предназначен только для отдельных внутренних тестовых сборок. Новый signed AAB/APK 1.0.46+47 проверен: пакет, min24/target36, upload-сертификат, SHA-256, ELF64 16KB и APK ZIP16KB. Физический телефон и обработка нового AAB в Play ещё не проверены. Пути/логи: отчёт исполнения; новый AAB не загружен в треки.

Важно: копия password.dpapi сама по себе не переносит пароль на другой компьютер. Нужна независимая резервная копия keystore и пароля в личном защищённом хранилище. До этого ключ защищён локально, но переносимый резерв не подтверждён. Пароль не отправлять в чат и не коммитить.
