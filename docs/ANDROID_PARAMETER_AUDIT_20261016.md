# Аудит параметров Android — 16.10.2026

Источник: весь android_config_v1 и текущие потребители в lib/features/game, lib/domain, lib/data/economy_store.dart, Supabase engine, simple_energy_sheet.dart. Ссылки в старых моделях сами по себе не считались работающей механикой.

Всего 120 конечных значений; доступны для редактирования 57, скрыты/зафиксированы 63. Дополнительно скрыты14 устаревших полей; прежние батарейные поля уже были скрыты. Ключи JSON сохранены для совместимости, старые параметры не публикуются как новые механики.

Достижения больше не разблокируются и не начисляются сервером Supabase, даже если старый клиент передаст такой запрос. Пороги наград за пробег/риск остаются: они используются сервером и результатом игры. Награды за Google/возраст остаются только совместимостью прежних клиентов.
