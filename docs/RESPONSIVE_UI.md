# Размер текста и экрана

12.10.2026. Основание: прямое указание Алексея уменьшать шрифт на маленьком экране, чтобы он помещался в окна. Реализация и приёмка: [задача](../memory/tasks/2026-10-12-responsive-text.md).

Общее правило Flutter/Android находится в `lib/ui/game_viewport.dart` и применяется ко всему Navigator: главный экран, модальные окна, магазин, аккаунт, рейтинг, результат и подтверждения используют один масштаб.

- Геометрия уже уменьшается пропорционально ширине относительно412 единиц. Этот масштаб также уменьшает отрисованный текст; повторно умножать шрифты отдельных экранов на ширину не нужно.
- Текст дополнительно учитывает доступную высоту без системных верхнего/нижнего отступов. На коротком экране его исходный размер уменьшается плавно, максимум ещё на10%. На обычном высоком экране этот дополнительный коэффициент равен1.
- Системное увеличение текста ограничивается по доступной ширине и высоте. Рабочий верхний предел до сжатия: примерно1.1–1.4; на узких экранах максимум1.15. Это рабочие значения реализации, а не отдельно выбранные пользователем числа.
- Сохранять нелинейное системное масштабирование разных размеров шрифта внутри предела. Не заменять его одним коэффициентом, измеренным на одной подписи.
- Высота клавиатуры не участвует в расчёте масштаба: открытие клавиатуры не меняет размеры текста и игрового поля. Поле ввода остаётся доступным через существующую прокрутку.
- Кнопки/области нажатия сохраняют прежние размеры в координатах игры; уменьшение текста не должно уменьшать их дополнительно.

Для нового окна проверить RU/EN на маленьких ширине **и высоте**, с обычным и крупным системным шрифтом, а также с клавиатурой. Длинные информационные блоки могут прокручиваться; названия кнопок и заголовки должны помещаться в своих областях. Не подменять проверку реального GameViewport проверкой отдельного компонента при фиксированном шрифте.

Тесты: `test/responsive_text_test.dart`, `test/game_viewport_test.dart`; подробные проверки отдельных поверхностей — `test/compact_windows_test.dart` и профильные UI-тесты. Визуальное направление остаётся [«Неоновая 3D-аркада»](ART_STYLE.md).
