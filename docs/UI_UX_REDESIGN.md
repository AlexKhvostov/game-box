# Актуальное направление после замечаний пользователя — 1.0.30

Крупные панели кандидата 1.0.29 отклонены пользователем и не опубликованы. Экспертный аудит ниже объясняет тот вариант, но не означает его принятия. Приоритет теперь — компактная привычная композиция, исходные цвета, таймер наверху и максимальная поверхность игрового ввода.

Подготовка и пакеты отменены. Книга способностей объясняет постоянные функции и оплату каждого использования. Магазин энергии описывает шесть существующих способов получения, условия, Stars и Plus. Верхние элементы визуально компактные; области касания сохранены. Профиль сокращён без дублирования имени/аватара, настройки устройства расположены компактно. Во время игры меню не открываются, весь веб-экран принимает жесты; текстовые уведомления и всплывающие подсказки запрещены. Шлем автоматический, отдельного жеста нет.

Браузерные снимки текущего направления сохраняются отдельно от отклонённого 1.0.29. Визуальная приёмка пользователем и реальные устройства не объявляются пройденными.

# UI/UX-переработка Untouch — 4 октября 2026

Исследование основано на исходном коде всех активных окон, четырёх снимках iPhone пользователя и воспроизводимых браузерных сценариях. Это экспертный аудит интерфейса, не интервью с игроками и не подтверждение роста удержания.

## Почему 1.0.28 не прошла визуальную приёмку

| Наблюдение | Влияние | Решение |
|---|---|---|
| Таймер перенесён на поле вопреки исходному замечанию | Перекрывает игру, нарушает привычную композицию | Вернуть в верхнюю строку Telegram; убрать только подпись; учитывать асимметричные кнопки |
| Сжатие текста до 10–12px | Плохая читаемость, ощущение технической панели | Основной текст 14–16px; подписи 12–13px; заголовки 22px |
| Разные классы/правила старых и новых окон | Несогласованные высота, фон, кнопки и прокрутка | Одна система заголовка, содержимого, статуса и нижнего действия |
| Малые крестики/шаговые кнопки | Неточная работа пальцем | Зоны касания минимум 44 CSS px как ориентир для веб-интерфейса |
| Пакет 0→2 через «+» выглядит как ошибочный счётчик | Неочевидное действие | Прямые кнопки «Без / 2 / 3», одно нажатие на пакет |
| Подготовка повторяет цену и подсказки несколько раз | Слабая иерархия | Выбор в содержимом, стоимость и единственное основное действие внизу |
| «Сохранено» выглядит вторым действием результата | Конкурирует с повторной попыткой | Сохранение — статус; повтор — основное действие; поделиться — вторичное |
| Закрытие окна результата сбрасывает игру; отложенный close может скрыть новое окно | Неожиданная навигация | Закрытие возвращает на прежний экран; окно меняется без гонки таймеров |
| Таблица рейтинга с мелкими колонками и вложенным modal | Плохое чтение на телефоне | Рейтинг списком, время справа, подробности отдельным экраном той же панели |
| Профиль перемешивает локальные настройки и серверное сохранение | Непонятно, что сохранено | Имя/приватность сохраняются явно; настройки устройства сразу, с объяснением |

## Система

Тёмный нейтральный фон, зелёный акцент только для основного действия/героя, умеренные границы без постоянного свечения. Шаг отступов 4/8/12/16/24; одинаковые радиусы 12/20. Одно активное окно. Заголовок и закрытие всегда доступны; прокручивается только содержимое. На маленькой высоте не уменьшаем весь текст, а разрешаем прокрутку. Нижняя зона учитывает Telegram safe-area. Тёмная/светлая темы, длинный ник, большой запас и сообщения об ошибках проверяются отдельно.

Сценарии: свайп → попытка; усиления → один выбор → играть или закрыть; энергия → бонусы/покупка → результат операции; результат → ещё раз/поделиться; рейтинг → период/подробности → назад; профиль → изменить → сохранить. Меню ставит игру на паузу; закрытие не списывает энергию и не теряет результат. Escape, кнопка Telegram «Назад», управление клавиатурой и восстановление фокуса применяются к одной панели.

## Источники и границы

- [Telegram Mini Apps](https://core.telegram.org/bots/webapps): safeAreaInset, contentSafeAreaInset и BackButton. Они используются для интеграции; реальные кнопки Telegram дополнительно требуют проверки на устройстве.
- [Apple Buttons](https://developer.apple.com/design/human-interface-guidelines/buttons): ясная иерархия действий и размеры зон касания. Значение 44 CSS px здесь — практический ориентир веб-реализации, не утверждение равенства CSS px и физических pt.
- [Apple Sheets](https://developer.apple.com/design/human-interface-guidelines/sheets): одно окно, предсказуемое закрытие и завершение задачи.

Приёмка: все активные окна, пустой/наполненный рейтинг, подробности, сохранение/ошибка профиля, ошибка награды, повторное открытие во время закрытия, Tab/Escape, тёмная/светлая тема, viewport 320/390/430 и короткая высота. Платежи/рекламные показы не выполняются автоматически. Финальные снимки и статус публикации — в ROADMAP.md.

## Реализация и функциональная приёмка

Введены ProductSheets и product.css. Активные окна: усиления, энергия, профиль, рейтинг, подробности и отправка карточки. Старые вспомогательные функции карточки/запросов используются повторно; новых UI-библиотек и внешних шрифтов нет. Подготовка сохраняет выбор сразу; профиль отдельно сохраняет имя/приватность, настройки устройства применяются сразу. В результате статус сохранения отделён от действий; кнопка повторной попытки главная. Дублирующий таймер под полем скрыт, основной возвращён в строку Telegram.

Навигация: инертный фон, фокус внутри окна, Escape/Telegram BackButton, возврат фокуса, защита несохранённого имени, задержка закрытия с отменой при новом открытии, возврат из Share к результату. VisualViewport учитывает доступную высоту панели при клавиатуре; реальные iOS-клавиатура и fullscreen ещё требуют приёмки. Серверные ответы сверяются с поколением окна; поздний старт ставит оплаченную попытку на паузу, поздняя награда не перерисовывает профиль.

Браузерные проверки: 320×560, 390×844, 430×932, обе темы, пустой/20 записей рейтинг, длинное имя с HTML как текст, внутреннее горизонтальное переполнение, размеры кнопок 44px, цена 28, ошибка/сохранение профиля, отмена редактирования, гонка close/open, поздние ответы, сохранение результата при возврате, свайп/второй палец/двойной тап, восстановление после сетевого отказа. Изображения — эмуляция с изолированными данными. Настоящие реклама, платежи и сообщения не выполнялись.
