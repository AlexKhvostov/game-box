## Проверки 06.10.2026

- `flutter test --no-pub`: 13 тестов прошли после переноса дремоты, загрузчика и таймера. Игровой UI при эмулированных 60/144 Гц не теряет время из-за округления каждого кадра; допуск учитывает задержку обновления HUD. Это не замер FPS настоящего телефона. Ошибка первого тестового прогона была точным сравнением дробных координат после отскока при нулевой скорости; заменено на допустимую погрешность 1e-9.
- Статическая проверка шести изменённых файлов — без замечаний; замечания оформления загрузчика устранены.
- HTTPS-чтение опубликованной конфигурации успешно; только GET, данные/публикация не менялись.
- HTTP 503, исключение сети, невалидный JSON/ответ, повреждённый кэш, перенос revision и дефолт JP1 проверены в тестах с подменённым HTTP, не настоящим Android.
- Обновлена только прямая зависимость `http`, прочие зафиксированные версии зависимостей сохранены. Firebase RC больше не вызывается из основной точки входа. Сам Firebase пока используется прежним профилем/Firestore до AP4.
