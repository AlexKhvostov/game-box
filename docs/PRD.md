# Untouch — продуктовое описание (PRD)

## 1. Суть продукта

**Untouch** — казуальная мобильная игра: игрок управляет своим квадратом и уворачивается от вражеских фигур на поле (не дайте себя коснуться). Цель партии — продержаться как можно дольше. После партии показывается место в рейтинге и процентиль («вы быстрее X% игроков»).

Короткий хук: *убегай дольше всех → сравни себя с миром → сохрани результат → сыграй ещё*.

Технический package: `com.boxgame.game_box` (репозиторий `game-box`). Бренд: **Untouch**.

## 2. Целевая аудитория

- Игроки казуальных аркад (возраст условно 12–35).
- Любят короткие сессии (2–30 секунд) и «ещё разок».
- Мотивируются соревнованием, рекордами и шерингом результата.

## 3. Ценность и вирусность

| Механика | Зачем |
|----------|--------|
| Время выживания | Понятная метрика |
| Место + процентиль | Эмоция и скриншот в чат |
| Опциональное сохранение ника | Контроль приватности |
| Лимит жизней + жетоны | Возвраты и монетизация без pay-to-win в топе |
| Daily Reward и награда раз в 8ч | Привычка заходить |

## 4. Игровой процесс

- Поле roughly квадратное.
- Игрок — квадрат, управление перетаскиванием пальцем.
- Враги появляются с краёв и движутся по прямым; столкновение = конец партии.
- MVP: враги — квадраты; далее прямоугольники и «палки».
- Сложность растёт со временем (скорость, частота, число врагов).
- Спавны **рандомные** на каждую партию (одинаковый дневной seed не используем).

## 5. Рейтинг

- После партии (если онлайн): место среди сохранённых результатов и процентиль.
- Игрок может **сохранить** результат (указав имя) или **не сохранять**.
- Имя не обязано быть глобально уникальным; при совпадении показываем суффикс (`Игрок#4821`).
- Глобальный топ — только «честные» партии без геймплей-бустов.

## 6. Экономика

### Жизни

- 1 старт партии = 1 жизнь.
- При 0 жизней — заморозка: нельзя начать игру, пока не купить пак жизней за жетоны (или не получить жизни иным способом в будущем).
- Стартовое число жизней, размер пака и цены — с сервера (Remote Config), не захардкожены.

### Жетоны (валюта; позже можно визуально назвать «кубики»)

**Получение:**

1. **Daily Reward** — раз в календарный день; размер может расти со streak.
2. **Кнопка «Получить жетоны»** — выдача, затем фриз **8 часов**.
3. **Покупка за реальные деньги (IAP)** — пакеты в магазине.

**Траты (MVP):** пак жизней (разморозка).  
**Позже:** убрать рекламу, радар направлений, скины и т.д.

## 7. Навигация (MVP)

Нижнее меню:

1. **Игра** — старт / поле / заморозка при 0 жизней.
2. **Рейтинг** — таблица лидеров.
3. **Профиль** — жизни, жетоны, daily, кнопка 8ч, магазин, настройки.

После партии: время, место, %, Сохранить / Не сохранять / Ещё раз.

## 8. Метрики успеха

- Retention D1 / D7.
- Среднее число партий на пользователя в день.
- % игроков, сохранивших хотя бы один результат.
- % забравших daily / 8ч-награду.
- Конверсия в IAP (после подключения покупок).

## 9. Что не входит в ближайший scope

- Ежедневный одинаковый набор спавнов.
- Сложные (непрямоугольные) фигуры.
- Платные бусты, дающие преимущество в глобальном топе.
- iOS-релиз (архитектура готова, билд — отдельный этап).
