# Границы действующего и исторического кода

18.10.2026, исправления ревью F14–F16.

`energy_sheet.dart` содержит только действующую навигацию. `energy_services.dart` — общие подтверждения покупок, статус Billing и форму обратной связи. `simple_energy_sheet.dart` больше не импортирует прежнее окно. Историческое оформление сохранено в `legacy_energy_sheet.dart`, используется отдельными регрессионными тестами и не достижимо из main. Проверка: `tools/verify_android_cleanup.py --apk <путь>`.

12 подтверждённо неиспользуемых ресурсов перечислены в ANDROID_ASSET_EXCLUSIONS.json. Они исключены из pubspec/Android bundle; исходные изображения/звуки сохранены для обратимости. Пять неиспользуемых вариантов GameArt убраны из кода. Размер исключённых исходников10 115 718байт — не обещание такого же уменьшения скачиваемого APK.

Прежние BalanceScreen/GamePlayScreen/freeze_sheet, firebase_mobile_client и remote_config_loader пока сохранены: они не входят в Android navigation, часть нужна старым тестам и другим целям. Полный список и доказательства — ревью ANDROID_CODE_REVIEW_20261018.md. Удаление всего старого backend/старой экономики и native Firebase Auth/Firestore dependencies потребовало бы отдельной миграции других целей; это не выполнено скрыто под Android-очисткой. Firebase Core/Remote Config остаются активными. Floors оставлен в dev-режиме ENABLE_FLOORS. Постоянный hidden+20 сохранён по явному решению пользователя.

Полный воспроизводимый тест: `powershell -File tools/test_android.ps1`. Шрифты зафиксированы с лицензией в test/fixtures/fonts; временный каталог tmp больше не нужен. Два прежних ожидания сверены с текущим интерфейсом: высота кнопки возраста50, нижний отступ Google13. Исторические Telegram fixtures проверяют прежнее перемещение по конечным точкам; намеренно отличающиеся непрерывные Android-столкновения проверяются отдельным тестом и физическим свайпом. Это не утверждение паритета новой Android-физики со старой опубликованной Mini App.
