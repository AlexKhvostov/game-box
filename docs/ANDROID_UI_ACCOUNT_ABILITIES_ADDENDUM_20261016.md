Важно: предыдущие большие широкие текстовые HTML-кнопки Алексей ОТВЕРГ. Использовать последний маленький вариант с красивыми иллюстрациями, а не линейными SVG-значками. Небольшая высота, примерно +20% ширины от маленького эскиза. Текущая нормализация в UI kit: видимая поверхность72×36 CSS px, область нажатия72×44px. Это ориентир пропорций, не команда механически умножать пиксели скриншота для Android.
Все шесть состояний: шлем выключен / включён / защита израсходована («Разбит»); прыжок выключен / готов / идёт откат. Статус ВНУТРИ кнопки. Круговая шкала и оставшееся время прыжка отображают реальную готовность; сейчас согласован показ отката2секунды. Внешняя геометрия, таймер и соседние блоки не скачут при смене статуса или начале попытки.
На главном экране у кнопок нет исчезающего «+1 энергии». Доплата остаётся в окне усиления, итоговая стоимость попытки — в текущей нижней подсказке.
До игры кнопка открывает соответствующее отдельное окно; она сама не включает режим одним нажатием. Во время игры сохранить нынешнюю семантику индикатора и реальные ограничения. Настоящий прыжок по-прежнему запускается вторым ОДНОВРЕМЕННЫМ касанием поля, не двойным тапом и не нажатием демонстрационной кнопки.
«Показать откат · 2 с», включение/расход защиты в панели и вкладка «Усиления» — инструменты UI kit, их НЕ переносить в игровое меню.
Рамка, текст, статусы, шкала должны быть настоящими компонентами; картинки допустимы для иллюстраций. Не накладывать отдельное лицо поверх шлема. Не переносить скриншот всей кнопки с запечённым текстом.
