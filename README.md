# Untouch landing

Static landing page for https://untouch.fun. Deployment branch contains only public landing files.

Render: Static Site, branch codex/landing-render, publish directory site, no build command.
Routing: rewrite /a/* to /invitation/index.html. Keep /.well-known/assetlinks.json public JSON.
Source release: landing-render-v1.0.79_20261028_140352_309, version 1.0.79.
Game applications, APIs, player data and credentials are not included.

Demo: standalone export of Untouch Playable 0.1.13, three attempts and no external assets. Screenshots: lossless conversions of physical Android231 RU captures. Original playable and Android source are unchanged.

Each mascot eye follows the pointer independently, including over the demo iframe. Demo shows only the board and top HUD; no outer scene or lower controls.
