# Game Box

Казуальная аркада: уворачивайся квадратом от врагов, соревнуйся в рейтинге, зарабатывай жетоны.

## Стек

Flutter (Android сейчас, iOS позже) + Firebase (онлайн-рейтинг и Remote Config — после настройки проекта).

## Запуск

```bash
flutter pub get
flutter run
```
