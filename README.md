# Game Box

Казуальная аркада: уворачивайся квадратом от врагов, соревнуйся в рейтинге, зарабатывай жетоны.

## Документы

- [Техническое задание (ТЗ)](docs/TZ.md)

## Стек

Flutter (Android сейчас, iOS позже) + Firebase (подключается на следующем подэтапе).

## Запуск

```bash
flutter pub get
flutter run
```
