# Работа над Telegram Mini App

## Физический Android для тестов

У Алексея есть Huawei P30 Lite; он часто может подключать его поUSB и разрешил использовать физическое устройство при необходимости (12.10.2026). Для плавности/управления/звука предпочитать проверку на телефоне в profile/release. Перед тестом проверять наличие устройства; при отсутствии попросить подключить. Основную игру не удалять и данные не очищать; автоматические замеры выполнять отдельным тестовым пакетом. Подробности: `docs/ANDROID_PHYSICAL_TESTING.md`.

Между активными тестами и после них останавливать игру на телефоне. Не оставлять врагов и музыку работать, пока исполнитель пишет код, ждёт сборку или готовит отчёт (прямое указание Алексея12.10.2026).

По новому указанию Алексея12.10.2026 на Huawei оставлено бодрствование экрана при USB-питании (`stay_on_while_plugged_in=2`), чтобы не требовать повторной разблокировки в тестах. Не сбрасывать эту пользовательскую настройку в0 при завершении; остановка самой игры обязательна.

Текущий план и статусы находятся в `docs/ROADMAP.md`. Перед работой над Telegram прочитай его и продолжай текущую очередь, учитывая новые указания пользователя.

- После работы над каждой задачей обновляй её статус, результаты проверок, текущий этап и журнал в плане. Различай готовый код, проверенный код и опубликованный релиз.
- Сохраняй согласованные решения об энергии, общем рейтинге и жестах управления из плана. Не отмечай ещё не реализованную механику завершённой.
- Каждый релиз собирай через `tools/build_telegram_web.ps1` с новой версией. Не перезаписывай прежние папки `releases/<buildId>/` и архивы.
- Для предоставленного пользователем FTP используй `tools/deploy_telegram_web.ps1`: резервная копия перед загрузкой, проверка файлов после загрузки и HTTPS-проверка версии. Секреты, данные игроков и опубликованный JSON не заменяются.
- FTP-пароль хранится в Windows DPAPI вне репозитория. Не записывай пароли и токены в код, документацию, архивы или вывод команд.
- Проверки платежей проводи без настоящих оплат и сообщений пользователям; для MySQL используй отдельные тестовые таблицы с обязательной очисткой. Не выдавай эмуляцию за проверку реального устройства.
